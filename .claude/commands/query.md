# Query

Вопрос: $ARGUMENTS

Шаги (полные правила в `CLAUDE.md`, секция "Workflow: Query"):

1. **Сначала ищи в `pages/`** через Grep / Glob / Read. НЕ читай `sources/` пока не убедишься, что в `pages/` ответа нет.

2. **Сформулируй ответ** на основе страниц. Каждое утверждение — со ссылкой на конкретную страницу: «по [[concepts/jtbd]]…», «как пишет [[people/seth-godin]]…».

3. **Если в `pages/` пробел**:
   - Скажи об этом честно.
   - Предложи: «есть в `sources/X.md` — запустить `/ingest sources/X.md` и потом ответить».
   - Не пересказывай источник на лету — это ломает принцип wiki.

4. **Если ответ содержательный** (длиннее 3 абзацев или может пригодиться позже):
   - Сохрани в `queries/YYYY-MM-DD-короткое-имя.md` с frontmatter:
     ```yaml
     ---
     title: Короткое имя
     question: <исходный вопрос>
     date: YYYY-MM-DD
     pages: [pages/concepts/jtbd.md, pages/people/clayton-christensen.md]
     ---
     ```
   - В тело — сам ответ.
   - Обнови `index.md` (секция Queries).

5. **Допиши в `log.md`**:
   ```
   YYYY-MM-DD HH:MM QUERY "<вопрос>" → queries/2026-05-04-foo.md (или "no save" если ответ короткий)
   ```

6. **Если что-то сохранил — закоммить**:
   ```bash
   git -C . add -A && git -C . commit -m "query: <короткая суть>"
   ```

## Принципы

- Wiki отвечает за тебя — если она пустая по теме, это сигнал что-то заингестить, а не повод фантазировать.
- Цитируй страницы, не выдумывай числа и факты.
- Короткие фактологические вопросы — отвечай прямо, без сохранения в `queries/`.
