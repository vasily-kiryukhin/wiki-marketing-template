# Weekly review

Полные правила в `CLAUDE.md`, секция "Workflow: Weekly".

## Что сделать

1. **Сводка по log.md за 7 дней**:
   - Сколько ingest'ов, сколько query, какие категории чаще трогали.
   - Какие источники добавляли (web / pdf / voice).

2. **Топ-5 горячих страниц** — те, где `updated` чаще всего двигалась за неделю. Это темы, в которые сейчас идёт активное накопление.

3. **3-5 stub'ов на развитие** — `status: stub`, в которых уже накопились ссылки из других страниц (т.е. сущность важна, пора писать развёрнуто).

4. **Короткий lint** — пройди по чек-листу из `lint.md`, покажи только критичные проблемы (битые ссылки, противоречия). Полный lint — отдельной командой.

5. **Сводка одним документом** — сохрани в `queries/YYYY-Www-weekly.md`:
   ```yaml
   ---
   title: Weekly YYYY-Www
   type: weekly
   week_start: YYYY-MM-DD
   week_end: YYYY-MM-DD
   ---
   ```

   ## Активность
   - Ingest: N
   - Query: N
   - Новых страниц: N
   - Обновлено: N

   ## Горячие темы
   - [[...]]
   - [[...]]

   ## Stub'ы на развитие
   - [[...]] — N входящих ссылок, не двигалась с YYYY-MM-DD

   ## Здоровье
   - Битых ссылок: N
   - Противоречий: N

   ## Что заметила (от агента)
   Свободный текст: что бросилось в глаза, какие связи между темами появляются, что стоило бы доисследовать.

6. Допиши в `log.md`:
   ```
   YYYY-MM-DD WEEKLY → queries/YYYY-Www-weekly.md
   ```

7. Закоммить.

8. Покажи пользователю краткое резюме (5-10 строк) и спроси, какую тему прокачать на следующей неделе.
